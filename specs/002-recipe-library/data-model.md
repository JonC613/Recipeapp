# Data Model: Recipe Library CRUD

## Recipe

| Field | Rules |
|---|---|
| `id` | Stable opaque identifier generated by the application. |
| `ownerUserId` | Nullable reserved field; not assigned in this personal MVP. |
| `title` | Required after trimming; maximum length is enforced at the application boundary. |
| `description`, `cuisine`, `category`, `notes` | Optional text fields. |
| `servings`, `prepMinutes`, `cookMinutes`, `totalMinutes` | Optional non-negative values. |
| `favorite` | Required boolean; defaults to false. |
| `source` | Required manual source for this feature. |
| `createdAt`, `updatedAt` | Required UTC timestamps. |

Relationships: one Recipe has zero or more Ingredients, Instructions, and Tags. Deleting a Recipe deletes all child records.

## Ingredient

| Field | Rules |
|---|---|
| `id` | Stable opaque identifier. |
| `recipeId` | Required parent reference. |
| `position` | Required, zero-based display order, unique within a recipe. |
| `originalText` | Required when the ingredient exists; preserved exactly as entered. |
| Other structured fields | Optional future-compatible quantity, unit, ingredient, preparation, and optionality values. |

## Instruction

| Field | Rules |
|---|---|
| `id` | Stable opaque identifier. |
| `recipeId` | Required parent reference. |
| `stepNumber` | Required, one-based display order, unique within a recipe. |
| `text` | Required non-empty text when the instruction exists. |

## Tag and Source

- A Tag is a trimmed non-empty label, unique case-insensitively within one recipe.
- Recipe Source is `manual` for this feature. URL, PDF, and text source fields remain absent but compatible with the stable domain model.

## State Transitions

```text
Unsaved manual entry ──save valid title──> Saved recipe
Saved recipe ──edit and save──> Saved recipe (updated timestamp)
Saved recipe ──favorite/unfavorite──> Saved recipe (favorite changed)
Saved recipe ──confirm delete──> Deleted
```

Validation or persistence failure leaves a prior recipe unchanged, or leaves a new entry unsaved with entered form values available for correction.
